# Preview Generation Briefs

The previews were generated with the built-in image-generation tool using current Galactic Sovereign operations, diplomacy, and combat screenshots as product references. The earlier Command Bridge and War Room explorations were also supplied when refining those two directions.

## Command Bridge

Create a production-quality 1440×1024 desktop strategy-game UI with a full-bleed galaxy map as the hero. Use a slim empire/resource ribbon, a contextual four-action ring around Solara Prime, a compact selected-system inspector, a prioritized attention queue, map overlays, time controls, and an explicit order preview containing cost, ETA, risk, and confirmation. Preserve Galactic Sovereign's navy-black, cyan, gold, violet, rose, angular console language. Avoid persistent tab bars, excessive cards, fake features, tiny text, and developer controls.

## War Room

Create a production-quality 1440×1024 fleet-operations UI with a narrow theater rail, broad strategic map, right command brief, three-route comparison, and a restrained four-lane persistent ledger. The selected fleet must flow from objective and route choice through readiness, costs, risks, and one `ISSUE ORDER` action. Preserve the current game's visual language while avoiding card mosaics, unreadable density, fake features, and developer controls.

## Adaptive Command Deck

Create a production-quality 1440×1024 system-management UI using a stable top ribbon, activity rail, breadcrumb and command palette, dominant Solara Prime system canvas, right context inspector, and adaptive bottom action deck. Show Aurelia selected, two construction actions accumulated into a plan, and an explicit cost/ETA/prerequisite preview before `CONFIRM CONSTRUCTION PLAN`. Avoid a radial ring, fixed three-column War Room layout, generic SaaS styling, fake features, and developer controls.
